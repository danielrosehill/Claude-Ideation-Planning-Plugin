Export the approved feature-ideas as a roadmap document.

## Procedure

1. Read all files in `approved/`.
2. Group by product/category.
3. Within each group, order by priority (High → Low).
4. Write `approved/roadmap-YYYY-MM-DD.md` with:
   - Executive summary (count per priority)
   - Per-product roadmap section
   - Per-idea: title, problem, proposed solution, priority, source
5. Report the path.
