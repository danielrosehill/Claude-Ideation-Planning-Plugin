Define negotiation parties. Writes files to `parties/`.

## Procedure

Ask the user for each party (minimum 3):

- **Identity** — name, role, brief description
- **Core interests** — non-negotiable priorities
- **Stated positions** — opening positions on each issue
- **Constraints** — red lines, mandates, external pressures
- **Negotiation style** — aggressive / conciliatory / legalistic / pragmatic / etc.
- **Alliances and tensions** — relationships with other parties
- **BATNA** — best alternative to negotiated agreement

Write each to `parties/<slug>.md` with clear headings.

Report how many parties were defined.
